# Owl Post — Sister's Birthday Letter

A Harry Potter-themed interactive birthday letter built with React + Vite + TypeScript and Framer Motion animations.

## What It Does

A 6-step animated experience:
1. **Owl Post intro** — Hedwig the owl flies with twinkling stars and mountain silhouettes
2. **Characters welcome** — Dumbledore, Harry, Hermione, Ron, and Dobby greet you (CSS pixel art)
3. **Sorting Hat** — Animated typing effect as the hat sorts you into all houses
4. **Spell Book** — Interactive spells: Expecto Patronum, Incendio, Accio Gifts, Riddikulus, Lumos, Confetti
5. **Birthday Letter** — Scrollable personalized letter with candle animations
6. **Grand Finale** — Full confetti and hearts celebration

## Tech Stack

- React 18 + TypeScript
- Vite (dev server on port 5000, `0.0.0.0` host)
- Framer Motion for animations
- Google Fonts: Cinzel & EB Garamond
- Deployed as a static site (build → `dist/`)

## Running

```bash
npm run dev     # development (port 5000)
npm run build   # production build
```
